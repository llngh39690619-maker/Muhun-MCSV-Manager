# Muhun MCSV Manager 1.0.8 使用說明

版本：1.0.8 stable
平台：Windows 10／11 x64

## 這個版本修正什麼

1.0.8 修正核心或模組包已建立完成，卻長時間停在「正在安全加入管理器」的問題。正式 Windows Service 現在會：

- 對暫時被防毒、索引器或其他程序占用的目錄搬移做有限次重試。
- 在同一次 Service 執行期間自動接續部分完成的匯入。
- 以檔案集合、大小及 SHA-256 驗證既有工作樹，完整時直接沿用，不重新複製大型 Java Runtime。
- 在電腦重啟、Service 重啟或搬移完成後尚未寫入狀態的情況下，安全接續同一筆交易。
- 保留玩家世界、設定、Server 核心與 Java 資料；不會因恢復失敗就刪除已跨過原子搬移邊界的內容。
- 讓桌面端在服務確實停滯時結束等待並顯示原因，不再永久轉圈。

## 正式發行目錄

正式發行目錄必須同時包含下列檔案與資料夾：

```text
gui-win-x64\
service-win-x64\
updater-win-x64\
providers\
mobile\
Install-MuhunMcsv.ps1
Uninstall-MuhunMcsv.ps1
Test-MuhunMcsvRelease.ps1
release-manifest.json
release-manifest.json.sig
update-manifest.json
update-manifest.json.sig
SHA256SUMS.txt
publisher.cer
```

`Muhun-MCSV-1.0.8-win-x64.zip` 是更新 payload，不是可直接雙擊使用的獨立安裝目錄。請勿只解壓 ZIP 後單獨執行其中的 EXE。

## 安裝或從 1.0.6 升級

1. 關閉不再使用的舊 Preview 視窗；不要手動刪除 `%ProgramData%\Muhun\MCSV`、Server、Runtime、世界或匯入交易目錄。
2. 以系統管理員身分開啟 PowerShell 7。
3. 將 `$release` 設成完整 1.0.8 發行目錄。
4. 驗證後執行安裝器：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned -Force

$release = 'C:\完整路徑\Muhun-MCSV-1.0.8-final-日期時間'
$installer = Join-Path $release 'Install-MuhunMcsv.ps1'

Get-AuthenticodeSignature -LiteralPath $installer |
  Format-List Status, StatusMessage, SignerCertificate, TimeStamperCertificate

& (Join-Path $release 'Test-MuhunMcsvRelease.ps1') `
  -ReleaseDirectory $release

& $installer -SourceDirectory $release
```

簽章狀態必須是 `Valid`，且必須有時間戳憑證。安裝器會自行保存 1.0.6 的 Service 設定及回復點、停止舊 Service、切換至 1.0.8、啟動並驗證新版本；不要先用 `sc.exe` 手動刪除或重建服務。

## 正確啟動 GUI

安裝成功後，使用開始功能表的「Muhun MCSV Manager」捷徑，或執行穩定啟動器：

```text
C:\Program Files\Muhun\MCSV\launcher\Muhun MCSV Updater.exe
```

不要直接執行版本資料夾內的 Service EXE。Service 由 Windows 背景服務管理，GUI 則由穩定啟動器選擇目前啟用版本。

## 恢復卡在「正在加入管理器」的既有工作

安裝 1.0.8 時不需要重建 Paper／Spigot 核心，也不要重新下載 Java。新 Service 啟動後會讀取原本的 durable import journal，自動驗證並接續。

正常結果：

- 背景工作轉為完成並自動清除成功紀錄。
- Server 出現在左側管理清單，且只出現一次。
- 玩家世界與原始核心檔案保持不變。
- 匯入暫存與 `.import-*` Runtime 工作目錄在交易完成後由 Service 安全清理。

若畫面顯示 `import.resume_required`，請先確認已安裝 1.0.8，再從「服務」重新啟動 `MuhunMCSV` 一次。不要手動搬移、合併或刪除 `%ProgramData%\Muhun\MCSV\servers`、`runtimes`、`imports`、`operations` 內的內容。

## 資料位置

正式 Service 的資料預設位於：

```text
C:\ProgramData\Muhun\MCSV
```

程式版本與穩定啟動器預設位於：

```text
C:\Program Files\Muhun\MCSV
```

請使用 GUI 的「開啟資料夾」功能查看受管理 Server。不要變更 `ProgramData` 內的 ACL、建立 junction／symlink，或讓同步軟體直接改寫執行中的 Server 樹。

## 移除

只有確定不再需要產品時，才以系統管理員 PowerShell 7 執行發行目錄內的 `Uninstall-MuhunMcsv.ps1`。移除前先建立備份；不要以手動刪除 Program Files 或 ProgramData 代替解除安裝流程。
