# Muhun MCSV Manager 1.0.6 使用說明

適用系統：Windows 10／11 x64
安裝 Shell：PowerShell 7.4 或更新版本

> 本文件說明 1.0.6 的安裝與操作方式，不代表未發布的成品已經通過正式建置。只使用完整、已簽章的 1.0.6 正式發行資產；若 [GitHub Releases](https://github.com/llngh39690619-maker/Muhun-MCSV-Manager/releases) 尚未提供完整資產，不要把 GitHub 自動產生的 Source code ZIP 當成安裝包。

## 1. 安裝前準備

1. 停止所有正在執行的 Server，等待備份、下載與建置工作結束。
2. 建立最新備份；重大版本變更前，另存一份離線備份。
3. 把「完整正式發行封裝」解壓到本機 NTFS 資料夾，保持目錄內容完整，不要單獨移動安裝腳本。

完整發行目錄至少包含：

```text
Install-MuhunMcsv.ps1
Test-MuhunMcsvRelease.ps1
publisher.cer
release-manifest.json
release-manifest.json.sig
update-manifest.json
update-manifest.json.sig
SHA256SUMS.txt
installed-version.v1.json
service-win-x64\
gui-win-x64\
updater-win-x64\
providers\
```

`Muhun-MCSV-1.0.6-win-x64.zip` 是簽章更新流程使用的 payload，不是可單獨執行的安裝目錄。`Install-MuhunMcsv.ps1` 必須和上述 manifest、憑證及實際 payload 位於同一個完整發行目錄。

## 2. 在管理員 PowerShell 7 安裝或升級

從開始功能表對「PowerShell 7」按右鍵，選擇「以系統管理員身分執行」。不要使用 Windows PowerShell 5.1。

```powershell
$PSVersionTable.PSVersion
```

`Major` 必須是 7，版本必須至少為 7.4。接著把下列範例的路徑改為完整正式發行目錄：

```powershell
$release = (Resolve-Path 'C:\path\to\Muhun-MCSV-1.0.6-final').Path

Get-ChildItem -LiteralPath $release -Force
```

### 2.1 核對發布者與簽章

先從正式 Release 公告或另一個信任管道取得發布者憑證 SHA-256，不可只信任同一個下載目錄內的數值。用以下指令顯示實際憑證指紋：

```powershell
$publisher = [Security.Cryptography.X509Certificates.X509Certificate2]::new(
    [IO.File]::ReadAllBytes((Join-Path $release 'publisher.cer')))
$publisherSha256 = [Convert]::ToHexString(
    [Security.Cryptography.SHA256]::HashData($publisher.RawData)).ToLowerInvariant()
$publisherSha256
```

指紋與正式公告完全一致後，自簽發行才需要建立本機信任：

```powershell
certutil.exe -addstore -f Root (Join-Path $release 'publisher.cer')
certutil.exe -addstore -f TrustedPublisher (Join-Path $release 'publisher.cer')
```

檢查安裝器簽章：

```powershell
$installer = Join-Path $release 'Install-MuhunMcsv.ps1'
$signature = Get-AuthenticodeSignature -LiteralPath $installer
$signature | Format-List Status, StatusMessage, SignerCertificate, TimeStamperCertificate

if ($signature.Status -ne 'Valid' -or $null -eq $signature.TimeStamperCertificate) {
    throw '安裝器簽章或時間戳無效，停止安裝。'
}
```

任何 hash、發布者、簽章或時間戳不符時，都不要以 `Bypass` 或關閉驗證繼續。

### 2.2 只調整當前 PowerShell 進程的原則

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned -Force
Get-ExecutionPolicy -List
```

不建議把整台電腦改為 `Unrestricted` 或 `Bypass`，也不建議為了安裝而使用 `AllSigned`；`AllSigned` 可能對 Windows 內建模組連續顯示「untrusted publisher」詢問。若 `MachinePolicy` 或 `UserPolicy` 有組織管理原則，`Process` 設定不會繞過該原則；請不要強制關閉它。

### 2.3 執行完整驗證與安裝

```powershell
& (Join-Path $release 'Test-MuhunMcsvRelease.ps1') `
  -ReleaseDirectory $release

& (Join-Path $release 'Install-MuhunMcsv.ps1') `
  -SourceDirectory $release
```

安裝腳本會再次驗證自身 Authenticode、同一發布者、RSA-PSS manifest、每個檔案的大小與 SHA-256、正式版本及安全路徑邊界，再建立或升級 `MuhunMCSV` Windows Service。

安裝器必須從 `$release` 目錄內的原始簽章腳本執行；不可複製腳本到其他資料夾再將 `-SourceDirectory` 指回發行目錄。

## 3. Service 與 GUI 必須一起升級

不要直接執行發行目錄中的 Service、Updater 或 GUI EXE，也不要手動覆蓋 `%ProgramFiles%` 內的檔案。正式功能依賴對應版本的 GUI、Service、IPC 契約與 Provider；單獨更換 GUI 會使資料夾、刪除、模組／插件或 Java 等功能 fail closed。

預設佈局：

```text
%ProgramFiles%\Muhun\MCSV\
├─ launcher\
├─ versions\1.0.6\
└─ active-version.v1

%ProgramData%\Muhun\MCSV\
├─ data\
├─ secrets\
├─ imports\
├─ servers\
├─ runtimes\
├─ backups\
├─ updates\
├─ plugins\
└─ logs\

%LocalAppData%\Muhun\MCSV\   GUI 個人設定與外觀資產
```

安裝完成後，從開始功能表開啟「Muhun MCSV Manager」。日常 GUI 不需要管理員權限。關閉 GUI 不會自動停止 Windows Service 及其管理的 Server、Web、通知或更新工作；請在 GUI／Web 明確停止 Server，或由系統管理員停止整個 Service。

## 4. 1.0.6 操作變更

### 4.1 啟動 Port

- 每次啟動前，Service 從 `25565` 起選擇當下最低可用的 TCP Listener Port。`25565` 未被 TCP 佔用時就會使用它；只有被佔用時才向上選擇。UDP-only 佔用不會排擠 Minecraft 主 TCP Port。
- 同時啟動會用 Service 內保留機制避免選到同一個 Port；啟動失敗、取消或進程終止後會釋放保留。
- Vanilla、Paper、Purpur、Folia、Spigot、CraftBukkit、Fabric、Forge、NeoForge、Mohist、Arclight、CatServer 與 Akarin 透過 `server.properties` 安全更新。Velocity 透過受控的 `--port` 參數更新。
- BungeeCord、Waterfall、Unknown 與 CustomJar 目前沒有可驗證的安全 Port adapter，啟動會明確 fail closed，不會猜測 YAML 格式、誤寫 `server.properties` 或繞過配置。需等待安全 adapter 實作，不要以改名核心類型來繞過。

### 4.2 Spigot BuildTools

- 第一次建置仍需從 Spigot 官方取得四個 Git repository，再執行 BuildTools，所以仍可能需要較長時間。
- 1.0.6 會保留受鎖定的官方 bare mirror source cache。後續建置若需要新 commit，先從固定官方 HTTPS remote 更新；驗證失敗才隔離並重建 cache。
- 每個建置工作仍使用 `--no-hardlinks` 獨立 clone；拒絕 hooks、alternates、reparse point 與非官方 origin。
- 這個優化是 Git source cache，不是完成 JAR cache；Maven 工作目錄仍為單次工作隔離。網路、Maven 依賴、CPU 與磁碟速度仍會影響時間。

### 4.3 線上模組包結果數

- 可選 `20／40／60／100`，預設 20。
- 切換來源、版本、Loader、分類、排序或結果數後，會取消過期要求並自動載入新結果，不需要再按「熱門推薦」或「搜尋」。
- CurseForge 會依官方每頁上限分頁、去除重複結果，並且不超過所選數量。篩選後的實際可用項目可能少於選擇值。

### 4.4 遠端管理與視窗尺寸

- 主工具列只保留一個「遠端管理」入口；遠端設定內可開啟 Web 控制台。
- 一般狀態拖曳視窗後會自動延遲合併並保存尺寸，程式關閉前完成最後寫入。最小化與最大化不會覆蓋正常視窗尺寸。
- 下次開啟時會依儲存尺寸還原；若螢幕、解析度或工作區已變更，會夾限到目前可見的螢幕工作區，避免視窗跑到畫面外。

## 5. 遠端 Web／手機管理

1. 在電腦 GUI 的「遠端管理」建立帳號；手機網頁不能建立帳號。
2. 對每個帳號設定角色、全域權限與逐 Server 權限。不要共用 Owner 帳號。
3. Web Host 只監聽 loopback；外網必須經由已核准的 HTTPS Tunnel，例如 Tailscale Funnel 或 Cloudflare Named Tunnel。不要把 listener 改為 `0.0.0.0`，不要使用 UPnP 或直接路由器 Port Forward。
4. 手機從該固定 HTTPS 網址登入。iOS 可用 Safari「加入主畫面」；Android 可使用正式發行資產內的已簽章 shell。
5. 「記住裝置」使用 `Secure`、`HttpOnly`、`SameSite` Cookie；不在網頁腳本保存密碼。遠端離線時不會排隊啟動、停止或其他變更操作。

Tailscale、Cloudflare 與其他外部服務需要各自的帳號、網路與可用性；MCSV 不保證第三方網址、方案或限額永久不變。

## 6. 資料保留、備份與回復

- 正式升級建立新的 `%ProgramFiles%\Muhun\MCSV\versions\1.0.6` 版本目錄，更新 active pointer、Service 與 stable launcher，不會以手動覆蓋方式更新舊版本。
- Server、地圖、玩家資料、備份、帳號、權限與秘密位於 `%ProgramData%\Muhun\MCSV`，不是版本程式目錄。升級不應刪除該資料根目錄。
- 安裝或升級中途失敗時，安裝器會嘗試回復 active pointer、舊 Service 設定與執行狀態、stable launcher 及本次新建的版本。若回復本身也報錯，請停止手動刪檔，保留完整錯誤與 log。
- Service 備份還原前會建立 pre-restore 回復點。模組包疊代更新會保留世界與玩家資料，並在失敗或健康檢查未通過時依 journal 回復。這無法保證任意第三方模組跨版本的資料語意相容性。
- 解除安裝預設保留 `%ProgramData%\Muhun\MCSV`。只有確定不再需要任何 Server、地圖、備份、帳號及秘密時，才能考慮使用 `Uninstall-MuhunMcsv.ps1 -RemoveData`。

## 7. 疑難排解

### PowerShell 顯示 ParserError 或 `#requires` 版本錯誤

- 確認視窗是 `pwsh.exe` 7.4+，不是 `powershell.exe` 5.1。
- 重新取得完整正式發行封裝；不要自行編輯、重新編碼或複製簽章區塊。
- 不要執行 repository 內未簽章的開發腳本來取代正式安裝器。

### 顯示「無法執行腳本」或連續詢問 untrusted publisher

```powershell
Get-ExecutionPolicy -List
Get-AuthenticodeSignature -LiteralPath (Join-Path $release 'Install-MuhunMcsv.ps1') |
  Format-List Status, StatusMessage
```

只信任經另一管道核對指紋的 `publisher.cer`，然後在當前進程使用 `RemoteSigned`。不要使用 `Bypass`。若 `MachinePolicy`／`UserPolicy` 強制管理，請由該電腦的原則管理者處理。

### 安裝顯示 Service 未通過 activation-ready

```powershell
Get-Service -Name MuhunMCSV
sc.exe qc MuhunMCSV
Get-Content -LiteralPath "$env:ProgramFiles\Muhun\MCSV\active-version.v1"
```

保留安裝器的完整錯誤輸出，並檢查 `%ProgramData%\Muhun\MCSV\logs`。不要手動改 SCM `binPath`、active pointer 或複製 EXE；安裝器本身會在健康驗證失敗時嘗試回復。

### GUI 按鈕停用、資料夾無法開啟或功能缺少

- 確認 `active-version.v1`、Windows Service 與開始功能表啟動的 GUI 都來自同一次 1.0.6 正式安裝。
- 關閉所有舊 GUI，再從開始功能表重開。不要從舊資料夾或下載目錄直接開 GUI EXE。
- 若本機操作員群組是剛建立或變更，重新登入 Windows 以取得新的安全權杖。

### `25565` 仍未使用或 Server 拒絕啟動

```powershell
Get-NetTCPConnection -State Listen -ErrorAction SilentlyContinue |
  Where-Object LocalPort -ge 25565 |
  Sort-Object LocalPort
```

確認實際有沒有 TCP listener 佔用 `25565`，並檢查 Server 核心類型。BungeeCord、Waterfall、Unknown 與 CustomJar 是預期的 fail-closed 限制，不是改用 `25566` 就能解決的錯誤。

### BuildTools 長時間停在 clone 或建置

- 第一次需要完整網路取得與編譯，不會因為 1.0.6 就變成即時完成。
- 確認可以連線 Spigot 官方 HTTPS 及所需 Maven 來源，並確認磁碟還有足夠空間。
- 不要在建置期間刪除工作目錄或 cache。如果 cache 驗證失敗，MCSV 會安全隔離後重建；不需要手動把不明 Git 目錄複製進去。

### 遠端 Web 無法連線

- 先確認 `MuhunMCSV` Service 正在執行、本機 Web 狀態正常，再檢查 Tunnel 狀態、HTTPS Origin 與帳號權限。
- 外部 Tunnel 失效時，不要把 loopback Web Host 改成公開 listener 當作替代方案。
- 網頁離線時的操作不會排隊；連線恢復後請重新確認當前 Server 狀態再操作。
