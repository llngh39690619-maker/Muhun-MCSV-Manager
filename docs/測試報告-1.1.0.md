## Windows 發布者信任模型

Windows 發行檔使用本專案的自簽 Code Signing 發布者，不是公開 CA 憑證，也不表示已取得 Microsoft SmartScreen 信譽。發布者資料：

```text
Subject: CN=Muhun MCSV Manager Release Signing, O=Muhun
Thumbprint: 60505A780C7BE0A03D1AA2086B48761D0956BBC7
publisher.cer SHA-256: 1a67e65dc9c367ac3247d0483edbe94dab38c5494859a43210c1ad4719e80b71
```

安裝前必須先透過獨立可信管道核對 `publisher.cer` SHA-256，由電腦擁有者或組織管理員將該憑證加入 `LocalMachine\Root` 與 `LocalMachine\TrustedPublisher`，再以 PowerShell 7 的 `AllSigned` Process scope 驗證並執行 `Install-MuhunMcsv.ps1`。不得使用 `Bypass`、`Unrestricted` 或只解壓 ZIP 後直接執行單一 EXE。

## 已驗證的產品邊界

- GUI、Service、Updater、簽署 PowerShell 安裝／移除／驗證腳本、Provider 與 Android 發行資料都由同一份正式 manifest 約束。
- Web Host 維持 loopback-only；遠端存取必須經已核准 HTTPS Tunnel，Service 仍在後端重新檢查帳號、權限與請求保護。
- 模組包更新的備份與 rollback 可保護檔案，但不能保證任意第三方模組跨版本的語意相容性。
- iOS 提供 PWA；Android 是受 HTTPS 來源限制的 WebView shell，目前不宣稱已上架 Google Play。
- 公開 GitHub 更新 feed 或 GitHub Release 尚未部署前，不應把 repository 自動產生的 Source code ZIP 當成正式 Windows 安裝包。
