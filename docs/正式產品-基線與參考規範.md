## Clean-room 參考原則

使用者指定 [MCSManager 官方 GitHub](https://github.com/MCSManager/MCSManager) 作為詳細功能參考，但禁止複製。Muhun MCSV 僅可參考公開文件中的需求分類與操作概念，例如：

- Web 控制層與程序執行層分工。
- 多使用者、細粒度權限與多語言。
- 即時控制台與多實例管理。
- 元件版本相容與更新前備份。

禁止取用或改寫下列內容：

- 原始碼、API 實作、資料格式與目錄結構。
- HTML、CSS、圖示、畫面配置、文案與翻譯。
- Plugin ABI、套件格式或建置腳本。

正式架構與命名必須由 Muhun MCSV 現有 `.NET 10 + WPF + ASP.NET Core` 基線自行設計。參考專案採 Panel／Daemon／Frontend 多元件架構；Muhun MCSV 則採單一 Windows Service 核心與同源 API，並不複製其部署結構。

## 參考後採取的不同設計

- 不加入目前沒有需求的分散式多節點控制。
- 不建立兩組公開管理埠；Web、控制台與事件都走同一個固定 HTTPS Origin。
- 不允許任意 Plugin 注入管理 UI。
- 不把第三方 assembly load context 誤稱為安全 sandbox。
- 不依 UI 按鈕可見性判斷權限；每次操作都由 Service 端授權。
- Windows 上採真正 SCM Service，而非只用批次檔啟動兩個前景程序。
