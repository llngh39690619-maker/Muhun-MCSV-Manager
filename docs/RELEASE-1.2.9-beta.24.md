# X MCSV 1.2.9-beta.24 — 客戶端探索、CurseForge 直裝與載入器修正（研發中）

本次 Beta Pre-release 包含 beta.20 之後、beta.21 至 beta.24 的累積變更。

## 主要變更

- 客戶端模組包探索整合左側分類、中央清單與右側固定預覽，加入實際分頁；模組、材質包與光影包下載也整合至主畫面。
- 點擊左側客戶端實例卡片即可返回該實例的啟動畫面，即使再次點擊目前已選取的實例也會生效。
- 統一模組包、模組、材質包與光影包的名稱及版本顯示，依內容種類呈現 Minecraft 版本與適用的載入器資訊。
- CurseForge 客戶端模組包在作者允許第三方下載時，可直接下載、驗證並安裝 Minecraft、Loader、必要檔案及 overrides。只有根模組包禁止第三方下載或缺少官方下載網址時，才提供官方專案頁備援。
- CurseForge 憑證入口移至一般設定，金鑰由目前 Windows 使用者的 DPAPI 保護；下載時重新核對檔案身分、散布政策與官方雜湊，安裝失敗會清除尚未提交的半成品。
- 缺少載入器標籤的版本會在背景補讀該檔案的 manifest；修正下載轉址與有界片段讀取，支援取消、切換版本及失敗重試。
- 遊戲版本、載入器與排序使用固定欄寬並靠右排列，窄視窗自動換行；長文字以省略號顯示，保留右側箭頭。

## 本機驗證

- 11 個測試專案共 3,594 / 3,594 項通過。
- Release 建置 0 警告、0 錯誤；26 個專案的 NuGet 弱點稽核為 0 advisories。
- 正式套件 manifest 驗證 30 個檔案；Windows 安裝器簽章、時間戳及 Android 簽署成品驗證通過。
- RLCraft 2.9.3／2.9、Pixelmon 9.1.0，以及 SkyFactory 4 的 4.2.4／4.2.2／4.1.0／4.0.8／4.0.5，八個版本皆透過官方 API／CDN 的 manifest 實測辨識為 Forge。

上述結果來自 beta.24 本機建置與驗收紀錄；載入器中繼資料實測不代表上述八個模組包都已完成整包安裝或遊戲啟動測試。
