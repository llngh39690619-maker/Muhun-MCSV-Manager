## 本版修正

### 背景建立完成後安全加入管理器

- 修正 Paper／Spigot 等核心完成下載或建置後，背景工作長時間停在「建立完成，正在安全加入管理器」的問題。
- 匯入交易在檔案搬移暫時失敗時採有界重試；同一 Service 行程內可進行有界恢復，不再無限等待。
- Service 重啟後可由持久 journal 恢復未完成交易；所有成功、取消、失敗及需重啟恢復狀態都會落盤。
- 重新接續時會驗證並重用已完成的 Server／Java Runtime 工作樹，避免重複複製大型 Runtime。
- GUI 對無進度匯入加入 stall timeout，並識別 `import.resume_required`，不再讓工作卡片永久顯示處理中。
- 加入 9 個針對搬移重試、崩潰窗口、重啟接續、Runtime 重用及 GUI timeout 的回歸測試。

### 不可變 Provider 版本處理

曾以不同簽署位元重新建置同一個 1.0.7 Provider，正式安裝器依安全規則拒絕同版不同 digest，並成功回復至仍可運作的 1.0.6，沒有遺失伺服器資料。最終成品因此升版為 1.0.8；沒有刪除或繞過 Provider 安全狀態。

## 已知限制

- `self-signed-local` 發布者憑證需要在每台 Windows 電腦信任；它不等同公開 CA 或 Microsoft SmartScreen 信譽。
- 簽署更新 URL 使用 Tailscale 網址，實際遠端更新仍取決於該節點、Funnel、DNS 及網路可用性。
- iOS 目前為可安裝到主畫面的 PWA；Android 為已簽署的 WebView shell，不是 App Store／Google Play 商店發行。
- Discord、Cloudflare、Tailscale、CurseForge 與其他第三方整合受各自帳號、條款、憑證及服務可用性影響。
- 模組包檔案級備份與回復無法保證任意第三方模組跨版本的語意相容性。
