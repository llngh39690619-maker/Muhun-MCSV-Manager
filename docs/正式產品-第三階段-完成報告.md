## Java 與基岩版產品邊界

- Java 版才會建立 X MCSV 受管理實例；只列 Mojang `release`，不列 snapshot、experimental 或舊 alpha／beta。
- 受管理 Loader 為 Vanilla、Fabric、Forge、NeoForge 與 Quilt 的官方穩定／recommended 版本。
- Forge／NeoForge 安裝器只接受固定官方 Maven 來源及對應 checksum；Fabric／Quilt 使用官方 meta profile。
- OptiFine／LabyMod 沒有納入靜默下載；只交給各自官方外部流程。
- 基岩版只開啟固定的 Microsoft 官方 Minecraft Launcher／Store 入口；不下載遊戲、不建立 Java 實例，也不套用 Java 記憶體、JVM 或 Loader 設定。

## 模組包來源邊界

- **Modrinth 客戶端：** 官方 API／CDN、安全 `.mrpack` 解壓、hash、host、格式、檔案數與大小驗證。
- **FTB 客戶端：** 顯示官方目錄，但安裝只交給經驗證的 `ftb://` 官方 App 協定；X MCSV 不爬取或重新託管 FTB 客戶端包。
- **CurseForge Server：** 使用者於當次流程提供 API Key，透過官方 API 並遵守作者 Distribution 設定；Key 不保存。
- **CurseForge 客戶端：** 不把 Key 寫入 EXE、不爬取網頁、不繞過第三方散布限制；使用者可改用 Modrinth 或官方 CurseForge App。

## 外部營運界線

- 本機自簽 Code Signing 憑證可證明同一專案金鑰與檔案完整性，但不等於公開 CA，也不會自動取得 Microsoft SmartScreen 信譽。
- Tailscale、Cloudflare、Discord、Microsoft、Mojang、Modrinth、CurseForge、FTB 與 Eclipse Adoptium 都受第三方帳號、網路、服務條款及可用性影響；不保證永久免費、無限制或永不失效。
- 檔案備份與 rollback 可保護世界及設定，但不能保證任意第三方模組跨版本的語意相容性。

缺少必要外部條件時，產品應 fail closed 或顯示可診斷錯誤，不得改採未驗證下載、公開本機 Port、網頁爬取或越權直接存取 Service 資料。
