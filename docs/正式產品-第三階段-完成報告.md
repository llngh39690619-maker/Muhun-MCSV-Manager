## 1.0.3 正式修正

- Service IPC API 1.5 正式接管「開啟資料夾」及「完全刪除 Server」；真實路徑與刪除能力只允許本機 ACL Named Pipe，不提供 Web／REST。
- GUI、Web 與手機可經 Service 取得有界、唯讀的頂層模組／插件及 Java Runtime 資訊；Web 每次要求均重新驗證精確 Server scope。
- Service readiness 同時要求 HTTP 基礎服務與 Named Pipe IPC 綁定成功，避免只有網頁存活就誤判可用。
- 自動更新 pending、terminal receipt、journal 與切換點可在程序中止或斷電後重入；完成 ACK 後才清理 pending。
- stable launcher 採簽署檔原子替換與失敗回復；升級會保存並還原 Service path、顯示名稱、描述、啟動模式、帳號、失敗動作、SDDL、SID、執行狀態與 Port。
- 更新保留管理器預設只保留兩個未受保護舊版本／套件／驗證快取；active、執行中、journal 前後版本、pending 與目前 stable／beta 候選一律受保護。
- 通知內容加入繁中／英文；FTB 秒／毫秒時間戳正規化並拒絕零值或超出範圍日期。
