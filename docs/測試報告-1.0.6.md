## 本版修正

### GUI 啟用握手

- GUI readiness Named Pipe 的接收工作與互動穩定性驗證並行開始，避免 GUI 很快送出 ready 並關閉連線後，broker 才開始等待連線而收到「管道正關閉中」。
- 明確 ready 失敗、互動驗證失敗及取消路徑使用連結取消來源；所有背景工作都會被有界取消並完整觀察。
- 未通過 readiness 的候選 GUI 仍會被終止，不以只有 `Process.Start` 成功冒充 GUI 已可操作。
- 1.0.6 使用新的產品及 first-party Provider 版本身分承載修正，不以不同內容重新發布既有 1.0.5 `.mcsvp`，維持 Provider 版本／digest 不可變規則。

### 安裝交易、回復與 Service 關閉

- 同版既有目錄會先依已簽署 release metadata、精確檔案集合、大小、SHA-256 及 reparse 邊界分類。
- 完全相同內容可安全重用；可辨識的未完成安裝只在未啟用時原子隔離後重建；無法辨識的內容 fail closed。
- 安裝失敗回復會還原 active pointer、stable launcher、Service 設定、failure actions 與既有執行狀態；本輪新版本先隔離，再做安全清理。
- Service 停止使用有界非同步等待。Host 關閉期限可容納 Minecraft graceful stop；通知工作採有界 drain／abort，不在正常取消時重新拋出取消例外。
- 最後通知 dispatch 具有獨立期限，避免 .NET Host 關閉時形成 `AggregateException`／事件 1026。

### 承接的 1.0.4 功能

- 真正啟動前從 `25565` 起選擇最低可用 TCP Listener Port；UDP-only 占用不排擠主 Port，同時啟動以 reservation 避免重複選號。
- Spigot BuildTools 使用受驗證且受鎖定的官方 bare mirror source cache；每次作業仍建立隔離 workspace。
- 線上模組包結果數可選 `20／40／60／100`；來源、版本、Loader、分類、排序或數量切換會取消舊要求並立即重新載入。
- 「手機遠端」與「Web 控制台」整合為「遠端管理」。
- 正常視窗尺寸會延遲合併保存，下次啟動依目前螢幕工作區安全還原。
