# X MCSV 1.1.0 使用說明

版本：1.1.0 stable

平台：Windows 10／11 x64

## 安裝或升級

正式發行目錄中的 `Install-MuhunMcsv.ps1` 是簽署安裝器；ZIP 是更新 payload，整個發行目錄也不是可直接挑一個 EXE 雙擊執行的 portable 版。

1.1.0 正式發行驗證已完成；Windows ZIP、manifest、發布者、Provider 與 Android 雜湊見 [1.1.0 正式測試報告](測試報告-1.1.0.md)。此處的 Windows 發布者是本專案自簽 Code Signing 憑證，不是公開 CA；截至本文件更新時，也不宣稱 GitHub Release 已發布。

1. 先從正式 Release 公告或另一個信任管道核對 `publisher.cer` 的 SHA-256；不要只信任與程式一起下載的文字或同名憑證。
2. 以系統管理員身分開啟 PowerShell 7.4 或更新版本。
3. 對使用本機自簽發布者的發行包，將核對過的公開憑證匯入這台電腦的 `LocalMachine\Root` 與 `LocalMachine\TrustedPublisher`。這是建立高信任，只有電腦擁有者或組織管理員應執行。
4. 確認安裝器簽章為 `Valid`，先執行磁碟驗證器，再執行安裝器。

```powershell
$release = 'C:\完整路徑\X-MCSV-1.1.0-final-20260828T083028Z'
$publisherPath = Join-Path $release 'publisher.cer'

$publisher = [Security.Cryptography.X509Certificates.X509Certificate2]::new(
    [IO.File]::ReadAllBytes($publisherPath))
$publisherSha256 = [Convert]::ToHexString(
    [Security.Cryptography.SHA256]::HashData($publisher.RawData)).ToLowerInvariant()
$publisherSha256
```

輸出必須為下列已驗證的 `publisher.cer` SHA-256；仍應先經另一個可信管道核對，再繼續：

```text
1a67e65dc9c367ac3247d0483edbe94dab38c5494859a43210c1ad4719e80b71
```

發布者 Subject 為 `CN=Muhun MCSV Manager Release Signing, O=Muhun`，Thumbprint 為 `60505A780C7BE0A03D1AA2086B48761D0956BBC7`。

```powershell
certutil.exe -addstore -f Root $publisherPath
if ($LASTEXITCODE -ne 0) { throw '無法將發布者憑證匯入 LocalMachine\Root。' }

certutil.exe -addstore -f TrustedPublisher $publisherPath
if ($LASTEXITCODE -ne 0) { throw '無法將發布者憑證匯入 LocalMachine\TrustedPublisher。' }

Set-ExecutionPolicy -Scope Process -ExecutionPolicy AllSigned -Force

$installer = Join-Path $release 'Install-MuhunMcsv.ps1'
$signature = Get-AuthenticodeSignature -LiteralPath $installer
$signature |
    Format-List Status, StatusMessage, SignerCertificate, TimeStamperCertificate
if ($signature.Status -ne 'Valid') { throw '安裝腳本簽章無效，請勿繼續。' }

& (Join-Path $release 'Test-MuhunMcsvRelease.ps1') `
    -ReleaseDirectory $release

& $installer -SourceDirectory $release
```

簽章或驗證器只要失敗就停止，不要使用 `Bypass`、`Unrestricted`、`Unblock-File` 或改寫腳本來繼續。升級會保留既有 Server、世界、玩家、備份、遠端帳號與設定，並以版本化 A/B 目錄保留可回復的上一版。不要手動刪除 `MuhunMCSV` Service、active pointer 或 `%ProgramData%\Muhun\MCSV`。

安裝成功後，請從 Windows 開始功能表的「Muhun MCSV Manager」相容捷徑啟動顯示名稱為 X MCSV 的 GUI。日後不需要再從發行目錄或 payload ZIP 直接執行 EXE。

## 主畫面模式

主畫面可在 Server 管理與 Minecraft 客戶端工作區之間切換：

- Server 管理仍由 `MuhunMCSV` Windows Service 持有；關閉 GUI 不會停止執行中的 Server 或已啟用 Web。
- Minecraft 客戶端由目前登入的 Windows 使用者執行；關閉 GUI 不會強制結束已啟動的遊戲。
- X MCSV 重開後只在 PID、精確啟動時間與 Java 完整路徑全部一致時恢復監看，避免誤連到其他程序。

## 加入 Microsoft／Minecraft 帳號

1. 進入 Minecraft 客戶端工作區。
2. 按「加入 Microsoft 帳號」。
3. 在 Microsoft 官方登入頁完成 OAuth。
4. X MCSV 會驗證有效的 Minecraft Java Profile 與所有權。

X MCSV 不會要求或保存 Microsoft 密碼。可更新的帳號 token 只保存在目前 Windows 使用者可解密的 DPAPI vault；登出帳號會清除對應本機授權。

## 建立 Java 客戶端

1. 選擇「Java 版」。只有 Java 版會建立受管理實例。
2. 選擇 Mojang 正式 release；snapshot、experimental、old alpha／beta 不會出現在清單。
3. 選擇 Loader：Vanilla、Fabric、Forge、NeoForge 或 Quilt。
4. OptiFine 與 LabyMod 沒有可安全驗證的完整公開安裝 API，因此只會開啟官方安裝器頁面。
5. 設定名稱、記憶體、解析度與全螢幕後建立。

X MCSV 會依遊戲版本選擇所需 Java major，從 Eclipse Adoptium 下載並驗證後存入獨立 client runtime 目錄。已存在且 major 相符的受管理 Java 會重用。

## 基岩版官方入口

選擇「基岩版」時，X MCSV 只把操作交給固定的 Microsoft 官方入口：先嘗試 Windows 的 `minecraft://` 協定，失敗時才改用 `ms-windows-store://pdp/?ProductId=9PGW18NPBZV5` 開啟官方 Minecraft Launcher Store 頁面。兩個入口都失敗時只顯示本地化錯誤。

基岩版不會被建立為受管理 Java 實例，X MCSV 也不會為它下載遊戲檔、選擇 Java／Loader、套用 JVM 記憶體或冒充 Microsoft 下載來源。

## 記憶體

- 「使用全域預設」：沿用程式設定中往後新增客戶端的預設值。
- 「自動」：依遊戲版本、Loader、模組數量、模組總大小及目前可用實體記憶體估算有界的最小／最大值。
- 「手動」：使用滑桿或數字指定安全範圍；不可讓最小值大於最大值。

自動模式不會把整台電腦的可用記憶體全部交給 Java，並保留 Windows 與 X MCSV 所需空間。

## 線上模組包

### Modrinth

客戶端可搜尋、排序、選擇遊戲版本、Loader、分類及每頁 20／40／60／100 筆。安裝前會驗證官方 API 身分、官方 CDN、`.mrpack`、SHA-512／SHA-1、路徑、檔案數與大小；選用檔案必須由使用者明確勾選。

### FTB

X MCSV 顯示官方 FTB 目錄、正式版本、Loader 與預覽圖。安裝按鈕只呼叫：

```text
ftb://modpack/install?packId=<官方 Pack ID>
```

FTB App 未安裝時會開啟官方下載頁。X MCSV 不爬取或直接重新託管 FTB 客戶端模組包。

### CurseForge

CurseForge 不提供免金鑰的官方下載 API。Server 端目錄可在使用者提供當次 API Key 時使用官方 API；Key 只在該次流程的記憶體中暫存。客戶端工作區不把 API Key 寫入 EXE、不爬取網頁，也不繞過作者的第三方散布設定；客戶端可使用 Modrinth，或以官方 CurseForge App 管理對應內容。

## 實例設定與內容

實例停止時可設定名稱、Java、記憶體、解析度、全螢幕、快速啟動、啟動後縮至系統匣、遊戲日誌、GPU 偏好、JVM 參數、環境變數、背景與圖示。遊戲執行中會封鎖可能破壞程序身分或啟動參數的一般設定寫入。

內容頁支援：

- 模組
- 資源包
- 光影包
- 地圖存檔
- 截圖

匯入、停用、啟用、移至回收區、還原與永久刪除會重新驗證實例根目錄、檔案身分及 reparse point；掃描與縮圖在背景執行，可於切換實例或關閉頁面時取消。

## 快速啟動與日誌

實例卡片的快速啟動只在實例可啟動且已選擇帳號時可用。若啟用「遊戲啟動後隱藏 X MCSV」，視窗會縮至系統匣，不會退出程式。

遊戲日誌以 75 ms 批次更新，待處理 queue 與畫面均有上限；畫面最多保留最近 2,000 行，完整遊戲 log 仍由 Minecraft 寫入該實例的 `logs` 目錄。

## Web、PWA 與手機

遠端 Web、iOS 主畫面 PWA 與 Android HTTPS shell 管理的是 Server 功能，並沿用 Windows Service 的帳號、權限、Origin、CSRF、Idempotency-Key 及 audit。Web Host 只監聽 loopback；公開存取需使用受控 HTTPS Tunnel。

## 外部服務限制

Microsoft、Mojang、Modrinth、FTB、Eclipse Adoptium、Tailscale、Cloudflare 與 Discord 都是第三方服務。X MCSV 會使用官方介面並在無法驗證時 fail closed，但不能保證第三方帳號、網址、免費方案或服務永遠不變。
