登入遠端控制

請使用電腦版 X MCSV 已新增的遠端帳號。手機端無法註冊或新增帳號。

尚未設定遠端帳號。請先在電腦版新增帳號；手機端不能註冊。

帳號為 6–32 位英文字母與數字，並以字母開頭。 請輸入 4–12 位半形數字。

保持登入需要固定網址。Cloudflare 隨機網址每次重新連線可能改變，因此此模式不會保存裝置登入。
